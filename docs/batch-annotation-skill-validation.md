# 批量批注 skill 优化与验收

2026-10-15。根据已完成的 263 条私密批注运行复盘，更新主 skill 并新增
`skills/weread/references/batch-annotations.md`。本次只改说明文档，不改 CLI/API。

## 依据与结构

按 writing-for-agents 的步骤、完成条件与按需读取原则组织。
[Agent Skills 官方规范](https://github.com/agentskills/agentskills/blob/main/docs/home.mdx)
允许在技能目录打包 references，并在执行时按需读取；
[社区实践](https://github.com/b-mendoza/agent-skills/blob/main/docs/best-practices/progressive-disclosure.md)
将常用规则留在入口，将特定任务细节放入明确路由的参考文件。
本次保留公共账号及认证规则，在入口加入批量任务指针和串行限速，详细流程集中在参考文件。

## 实际问题与规则覆盖

| 运行证据 | 固化规则 |
| --- | --- |
| 263 项中 24 项含 41 个链接，纯文本提取最初丢掉 href，后续补回 | 写前保留完整正文及链接目标，按项验收链接 |
| 263 条批注对应 256 个不同范围 | 划线按范围复用，批注按稳定来源项 ID 查重 |
| 5 条已有批注需要补全 | 读取旧正文，保存哈希，编辑前核对冲突；整段替换并明确私密 |
| 32 项需要区分上下文或版本 | 多候选不取第一项，修订处选择实际存在的锚点 |
| 主流程 1033 次 CLI 调用，至少间隔 2 秒，未出现限流 | 全部远程调用走串行队列；该间隔不是服务端配额承诺 |
| 列表接口返回 -2003 | 按接口和消息诊断；使用确定 ID 回读，不将列表错误等同于无笔记 |
| 每次写入保存意图、回执及状态 | 超时结果不明先对账；回执已保存时恢复 ID，不重发创建 |
| 263 条逐一确认私密、位置及完整正文 | 明确逐项完成条件，未验证项不得计为成功 |

另覆盖恢复时的常见故障：划线成功但批注未开始、响应已保存但状态未更新、
读取失败、源版本变化和用户手动修改。它们是文档分支审查，并非本次故障注入测试。
